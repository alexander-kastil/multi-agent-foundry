# Foundry Agent Service: Tools, Knowledge & Memory

## Content

- **Prompt agents**: you publish a versioned definition and the service runs it
- Tools for code, documents, the web and a managed browser, plus **enterprise knowledge**
- Agents that **remember** their users, plan their own work and speak

## Speaker Notes

This is the opening slide of the module: Foundry Agent Service hosts the agent, and the module adds one capability per topic.

Prompt agents: you publish a versioned definition of a model, instructions and tools, and the service runs it. Every later topic builds on that first version.

Tools and knowledge: the agent runs code, reads documents, browses the web and retrieves from enterprise knowledge. Every topic has a runnable project and a demo guide with real captured output.

Memory, loops and voice: the agent remembers its users, plans its own work and finally speaks. Classic threads and runs are not taught, because they retire on March 31, 2027.

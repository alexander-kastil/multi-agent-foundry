# Agentic Business Processes with Microsoft Foundry, Agent Framework & Copilot Cowork

A five-day pro-code masterclass for Agentic Architects and AI Engineers who finished AI-103 and want to know what comes next. The class opens where certification stops: production Foundry architecture, real identity patterns, and the agent infrastructure that runs at scale.

Microsoft Foundry is covered as architects use it. The new resource model, Model Router strategy, and Foundry SDK 2.0 pipeline composition set the foundation. Agent Identity becomes first-class with Entra service principals and On-Behalf-Of flows. MCP moves from concept to production infrastructure via Azure Functions and the Foundry Toolbox, with trace-level evaluation and Prompt Optimizer closing the feedback loop.

The Microsoft Agent Framework separates concerns across three architectural layers. AgentSession persistence, Agent Skills, Second Brain long-term memory patterns, and A2A protocol adapters give agents the composability that survives production. Durable Agents on Azure Durable Functions add checkpointing, human approval gates, and cost-efficient scale-to-zero execution.

Multi-agent team design and Microsoft 365 Copilot Cowork integration complete the picture. Magentic orchestration handles complex team topologies with stall detection and replanning. Foundry agent teams are wrapped as MCP servers, secured with Entra SSO and On-Behalf-Of, assembled into Cowork plugins, and distributed to the enterprise through the M365 Agents Toolkit.
